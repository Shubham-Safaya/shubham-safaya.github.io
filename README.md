# shubham-safaya.github.io

Personal site of **Shubham Safaya** — Senior Product Manager at Walmart Global Tech, building the identity layer of retail media: data identity, customer ads personalization, and privacy-by-design.

**Live:** https://shubham-safaya.github.io

## Design

- Single self-contained `index.html` — zero frameworks, zero build step
- The animated background is a **live identity graph**: nodes (signals) drift, link, and resolve into clusters with gold pulses — the product domain rendered as generative art
- Editorial typography: Fraunces (display serif) + Inter + JetBrains Mono
- Scroll-choreographed reveals via IntersectionObserver, scroll-progress bar, marquee focus strip
- Accessible: skip link, semantic landmarks, `prefers-reduced-motion` support, keyboard-friendly nav
- SEO: Open Graph tags + JSON-LD Person schema
